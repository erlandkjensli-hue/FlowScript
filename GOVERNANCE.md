# Governance

## Project status

FlowScript is an experimental open project. The specification is not a ratified standard.

The repository exists to develop the semantic model openly, test it against different application types, and determine whether a durable language can emerge from that work.

## Maintainer

**Erland Kjensli** is the project initiator and original author and currently serves as the repository maintainer.

The maintainer is responsible for:

- protecting the project's scope and principles
- reviewing contributions
- maintaining repository infrastructure
- making final decisions while the project remains in an experimental phase

## Decision making

Discussion and evidence should guide changes.

For significant semantic changes, the preferred process is:

1. describe the problem
2. discuss alternatives
3. test the alternatives with examples
4. document the resulting decision
5. update the specification if appropriate

Disagreement is expected and welcome. A proposal does not need to become part of the language simply because it is popular.

## Future governance

As the project develops, governance may evolve toward a broader maintainer group or another documented decision-making model.

Any such change should be documented publicly in this file.
