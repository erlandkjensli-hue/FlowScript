# Code of Conduct

FlowScript is an open technical project. People should be able to disagree about ideas without making disagreement personal.

## Expected behavior

Participants are expected to:

- be respectful and professional
- discuss technical ideas on their merits
- welcome good-faith questions
- identify uncertainty clearly
- avoid personal attacks, harassment, and discriminatory behavior
- respect different backgrounds and levels of experience

## Unacceptable behavior

Unacceptable behavior includes harassment, intimidation, threats, personal attacks, discrimination, sexual harassment, doxxing, and deliberate disruption of project collaboration.

## Enforcement

Project maintainers may remove, edit, or close contributions that violate this code of conduct and may restrict participation when necessary to protect the project community.

For sensitive concerns, contact the project maintainer privately through GitHub rather than posting personal or security-sensitive information publicly.

## Scope

This code of conduct applies to the repository, discussions, issues, pull requests, and other project spaces operated by the FlowScript project.
