# Security Policy

## Scope

FlowScript is currently an experimental specification project. Security issues may affect future parsers, validators, editors, visualization tools, or reference implementations.

## Reporting a security issue

Please do not publish sensitive security details in a public issue.

Use GitHub's private vulnerability reporting where available. If private vulnerability reporting is not enabled, use a private GitHub communication channel with the project maintainer.

When reporting an issue, include:

- affected component or file
- relevant version or commit
- reproducible steps
- potential impact
- any available mitigation

Please allow maintainers reasonable time to investigate before public disclosure.
